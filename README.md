# GEO

Minimal academic project focused on cloud-native deployment. This app is deployed on Google Cloud Run.

## Overview
- Purpose: academic study of cloud deployment patterns
- Platform: Google Cloud Run (GCP)
- Stack: Next.js (App Router), TypeScript, Prisma

## Local Development
1. Install dependencies: `pnpm install`
2. Start dev server: `pnpm dev`
3. Open: http://localhost:3000

## Deployment
This project is deployed on GCP Cloud Run. Deployment configuration is handled outside this repository.
